## 项目背景

运动想象研究经常需要同时查论文、数据集说明与实验设置，也需要对脑电数据进行实际计算。文献回答需要可核对的原文；某次模型分析则需要真实运行得到的产物。项目希望把这两类依据连接到一个研究工作台，同时保留它们各自的来源与能力边界。

## 工作台的三个入口

| 模式 | 作用 | 边界 |
| --- | --- | --- |
| 对话 | 一般问题、选定文件或图片的理解，可按需联网 | 普通问题不自动调用私有知识库或 EEG 模型 |
| 文献解析 | 检索资料、融合排序并生成带来源的回答 | 引用编号存在不等于每项主张都得到支持 |
| Agent 研究 | 规划并执行受控工具，分析登记样本或读取已有产物 | 工具及参数需经后端校验；模型建议不等于已经执行 |

## 技术链路

**资料入库：** PDF、DOCX 和 Markdown 分别解析，原件归档 MinIO；保留文档身份、章节和来源信息，切块后通过 BGE-M3 生成稠密与稀疏表示并存入 Milvus。MongoDB 保存会话和任务等记录。图像生成说明用于辅助检索，不能替代原文和原图。

**文献问答：** 结合历史理解问题，执行普通检索、HyDE 检索与 MCP 网页搜索；本地候选经 RRF 融合，再与网页候选进入精排和证据选择。回答生成后检查来源及主张支持，必要时说明证据不足。HyDE 生成的假设文本不是事实来源。

**受控工具：** 模型提出计划，后端先验证工具白名单、参数、依赖与来源，再调用实际工具；执行后可进行有限观察与补查。记录任务、执行轨迹与产物身份，使结果可以被查看和追问。

## EEG 模型能力与限制

- **CBraMod：** 使用预训练编码器处理兼容单试次并保存表征。该能力没有训练好的运动想象分类头，不据此输出类别。
- **DWDaNet / DWTNet：** 接入本地已训练的 2a 四分类权重，当前适配约定为 22 通道、250 Hz、4 秒数值试次；类别包括左手、右手、双脚和舌头。输入顺序、预处理与训练来源必须符合适配条件。
- 两个分类模型的归一化统计依据现有训练来源数据重建；模型分数未经校准，不能当作分类准确率或可靠置信度。波形截图不等于可供模型执行的完整数值信号。

## 验证与后续方向

项目将回归测试、真实外部调用与效果评测分开记录。曾针对切块策略、召回和精排进行有条件比较，也保留未成功的尝试。一次 5 次请求的性能记录只能描述当时机器与配置，不能代表稳定服务指标；评测也不能以合法引用代替事实支持。

后续重点是扩大并维护有来源锚点的评测集，分别检查检索覆盖、排序、回答支持与任务完成情况；进一步改进任务恢复、多用户协调和模型输入适配。任何新增数据集和分类结论都需要单独验证。
